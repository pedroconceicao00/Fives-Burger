# Fives Burger

🍔 Five's Burger
O Five's Burger é um projeto de website desenvolvido para uma hamburgueria, criado com o objetivo de apresentar a marca, seus produtos e sua identidade visual de forma moderna, atrativa e responsiva.

O projeto busca proporcionar uma experiência agradável ao usuário, permitindo que ele conheça a história da Five's Burger, navegue pelo cardápio, visualize informações sobre os produtos e encontre facilmente os canais de contato da hamburgueria.

🎯 Objetivo
O principal objetivo do projeto é desenvolver uma presença digital para a Five's Burger, utilizando uma interface moderna e organizada para apresentar a hamburgueria aos seus clientes.

Além de funcionar como uma vitrine digital, o site foi pensado para transmitir a identidade da marca através de elementos visuais, cores, tipografia, imagens e animações.


📌 Páginas do projeto

🏠 Início
A página inicial apresenta a Five's Burger e funciona como o primeiro contato do usuário com a marca.
Nela são utilizados elementos visuais de destaque, chamadas para ação e informações que direcionam o visitante para as principais áreas do site.

🍔 Cardápio
A página de cardápio apresenta os produtos disponíveis da Five's Burger de maneira organizada e visualmente atrativa.
Os produtos são apresentados com informações relevantes, permitindo que o usuário conheça melhor as opções oferecidas pela hamburgueria.

📖 Sobre
A página Sobre foi desenvolvida para apresentar melhor a identidade da Five's Burger.
Através de uma navegação vertical com diferentes seções, o usuário pode conhecer a história, os valores, o propósito e os diferenciais da marca.
A página também utiliza elementos visuais, animações durante a rolagem e uma apresentação destacada da identidade da hamburgueria.

📞 Contato
A página de contato reúne as principais formas de comunicação com a Five's Burger, facilitando o acesso do cliente às informações da hamburgueria.
A estrutura foi desenvolvida para ser simples, organizada e responsiva, permitindo que as informações sejam acessadas tanto em computadores quanto em dispositivos móveis.

🎨 Identidade visual
A identidade visual do projeto utiliza principalmente preto, laranja e branco, criando uma aparência moderna e marcante.
O laranja é utilizado como cor de destaque para representar energia, sabor e personalidade, enquanto o preto contribui para uma aparência mais sofisticada. O branco é utilizado para garantir contraste e facilitar a leitura.
A identidade também conta com elementos relacionados ao universo das hamburguerias, como hambúrgueres, utensílios e detalhes gráficos.

🛠️ Tecnologias utilizadas
O projeto foi desenvolvido utilizando tecnologias fundamentais para desenvolvimento web:

HTML5 — estrutura e organização das páginas;

CSS3 — estilização, layout, responsividade e animações;

JavaScript — interações e comportamentos dinâmicos da interface.
